# SchoolPro

Plateforme scolaire futuriste.

## Fonctionnalités

- Comptes élèves
- Connexion sécurisée
- Comptes professeurs
- Panel créateur
- Création de professeurs
- Gestion des utilisateurs
- Publication de leçons
- Matières scolaires
- Quiz
- Espace et planètes

## Installation

Installer Node.js 20 ou supérieur.

Dans le terminal :

npm install

Puis :

npm start

Ouvrir http://localhost:3000

## Déploiement

Connecter le dépôt GitHub à Render.

Commande de construction :
npm install

Commande de démarrage :
npm start

Configurer les variables privées sur Render :
CREATOR_EMAIL
CREATOR_PASSWORD
SESSION_SECRET
DB_FILE
NODE_ENV
